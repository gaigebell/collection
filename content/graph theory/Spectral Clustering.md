> 谱聚类是一种基于图拉普拉斯矩阵特征值的聚类方法，它将聚类问题转化为图的划分问题，通过谱松弛获得近似最优解。本节课深入理解谱聚类的理论基础：从图割出发，推导出拉普拉斯矩阵，解释为什么特征向量能揭示图的社区结构。

---

## 1. 图划分问题

### 聚类的图视角

> [!abstract] 核心思想
> 将聚类问题理解为**图的划分**问题：
> - 顶点 = 数据点
> - 边权重 = 相似度
> - 目标：找到"内部紧密、之间稀疏"的顶点分组

### 图划分的数学表达

将顶点集 $V$ 划分为 $k$ 个不相交的子集 $A_1, ..., A_k$：

$$\text{优化目标} = \min_{\text{划分}} \sum_{i=1}^{k} \text{cut}(A_i, \overline{A_i})$$

其中 $\text{cut}(A, B) = \sum_{i \in A, j \in B} w_{ij}$

> [!tip] 直观理解
> 好的划分应该让"跨组的边权重最小"——不同簇之间的连接应该稀疏。

---

## 2. 两种目标函数

### 2.1 RatioCut

$$\text{RatioCut}(A_1, ..., A_k) = \sum_{i=1}^{k} \frac{\text{cut}(A_i, \overline{A_i})}{|A_i|}$$

- **惩罚**：小簇被割边"惩罚"更重（除以 $|A_i|$）
- **目标**：避免产生太小的簇

### 2.2 Normalized Cut (Ncut)

$$\text{Ncut}(A_1, ..., A_k) = \sum_{i=1}^{k} \frac{\text{cut}(A_i, \overline{A_i})}{\text{vol}(A_i)}$$

其中 $\text{vol}(A) = \sum_{i \in A} d_i$（子集内部度之和）

- **惩罚**：考虑簇的"大小"（按度加权的体积）
- **目标**：平衡各簇的"权重"

> [!info] RatioCut vs Ncut
> - RatioCut：偏好**节点数平衡**的划分
> - Ncut：偏好**度（权重）和平衡**的划分
> - Ncut 在实际应用中更常用，因为它考虑了边的权重

## 3. 拉普拉斯矩阵 Laplacian Matrix

### 3.1 定义

设 $G = (V, E)$ 为无向加权图，权重矩阵 $W = (w_{ij})$：

$$L = D - W$$

其中：
- **度矩阵** $D = \text{diag}(d_1, ..., d_n)$，$d_i = \sum_j w_{ij}$
- **邻接矩阵** $W$

> [!important] 拉普拉斯矩阵的性质
> 1. **对称半正定**：$L = L^T, L \succeq 0$
> 2. **行和为零**：$L \mathbf{1} = \mathbf{0}$
> 3. **特征值**：$0 = \lambda_1 \leqslant \lambda_2 \leqslant ... \leqslant \lambda_n$
> 4. **特征向量**：对应特征值 $\lambda$ 的特征向量与 $\mathbf{1}$ 正交（$\lambda > 0$ 时）

### 3.2 拉普拉斯矩阵的二次型

> [!theorem] 核心定理
> $$x^T L x = \frac{1}{2} \sum_{i,j} w_{ij} (x_i - x_j)^2$$

> [!proof]- 证明思路
> 展开 $x^T L x = x^T D x - x^T W x = \sum_i d_i x_i^2 - \sum_{i,j} w_{ij} x_i x_j$
> 重新整理后得到上式。

> [!info] 物理意义
> 这个二次型衡量了**相邻顶点之间标签差异**的加权和：
> - 如果相邻顶点标签相同 $(x_i = x_j)$，贡献为 0
> - 如果相邻顶点标签不同，贡献为权重乘以差异平方

## 4. 谱松弛

### 4.1 从离散到连续

原始的图划分问题是**离散的**（指示向量 $h_i \in \{0, 1\}$），难以优化。

**Relaxation**：将约束放宽为 $h_i \in \mathbb{R}$：

$$\min_{H^T H = I} \text{tr}(H^T L H)$$

其中 $H$ 的每列是一个划分向量的松弛。

### 4.2 瑞利商与特征值

> [!theorem] 瑞利商定理
> 对于对称矩阵 $L$，瑞利商 $\frac{x^T L x}{x^T x}$ 的最小值等于最小特征值 $\lambda_1$，最大值等于最大特征值 $\lambda_n$。

因此，松弛后的优化问题的解由**特征向量**给出！

### 4.3 二划分的解

对于二划分问题 $(A, \bar{A})$：
- RatioCut $\Leftrightarrow$ 使用**标准拉普拉斯矩阵** $L$
- Ncut $\Leftrightarrow$ 使用**归一化拉普拉斯矩阵** $L_{sym} = I - D^{-1/2} W D^{-1/2}$ 或 $L_{rw} = I - D^{-1} W$

**解**：取第二小的特征向量（$L$ 的 Fiedler 向量），按符号划分：
- $x_i \geqslant 0 \Rightarrow A$
- $x_i < 0 \Rightarrow \bar{A}$

> [!tip] 直观理解
> Fiedler 向量给出了一种"平滑"的顶点标签，使得相邻顶点倾向于有相似的标签——这正是聚类想要的！

## 5. 谱聚类算法

### 5.1 标准谱聚类流程

```
输入：相似度矩阵 S，簇数 k
输出：k 个簇

1. 构建加权图 G = (V, E, W)
2. 计算度矩阵 D 和拉普拉斯矩阵 L
3. 计算 L 的前 k 个最小特征向量 h₁, ..., hₖ
4. 构建矩阵 H = [h₁, ..., hₖ]
5. 对 H 的行向量进行 k-means 聚类
6. 原始顶点根据其所在簇划分
```

### 5.2 两类划分算法（二分法）

```
输入：图 G，簇数 k
输出：k 个簇

1. 使用 Ncut 划分图（取第二特征向量）
2. 将图划分为两个子图
3. 递归地对每个子图进行划分
4. 直到得到 k 个簇
```

### 5.3 推荐：正则化拉普拉斯

| 拉普拉斯矩阵 | 定义 | 适用场景 |
|-------------|------|---------|
| **标准** $L = D - W$ | 对称半正定 | RatioCut |
| **对称归一化** $L_{sym} = I - D^{-1/2} W D^{-1/2}$ | 对称 | Ncut |
| **随机游走** $L_{rw} = I - D^{-1} W$ | 非对称 | Ncut |

> [!info] 推荐使用
> - **$L_{rw}$（随机游走拉普拉斯）** 在实践中效果通常最好
> - 归一化版本对度分布不均匀的图更鲁棒

## 6. 理论解释：为什么特征向量有效？

### 6.1 连续 vs 离散

| | 连续松弛 | 离散解 |
|---|---|---|
| 目标 | $\min h^T L h$ | $\min \text{Ncut}$ |
| 约束 | $h^T h = n$ | $h_i \in \{0, 1\}$ |
| 解 | 特征向量 | 阈值化特征向量 |

### 6.2 误差分析

> [!theorem] 非正式结论
> 如果图有 $k$ 个"好的"簇，那么前 $k$ 个特征向量会"指向"这些簇的方向。

**关键洞察**：
- 每个簇内部边权重高，簇间边权重低
- 拉普拉斯矩阵的二次型惩罚"跨簇"的差异
- 最小化 $h^T L h$ 就是在找"内部一致"的标签

### 6.3 几何解释

将特征向量视为 $n$ 维空间中的点：
- 前 $k$ 个特征向量张成一个 $k$ 维子空间
- 好的簇在这个子空间中也是"可分的"
- k-means 在这个投影空间中找出聚类

> [!tip] 直观类比
> 想象一个西瓜——外面的瓜皮（噪声）遮住了里面的瓜瓤（结构）。谱聚类就像找到了一个"透视角度"，让我们能看到内部的瓜瓤（簇）。

## 7. 谱聚类的性质与局限

### 优点

| 优点 | 说明 |
|------|------|
| **通用性** | 不假设簇的形状（凸、非凸都可以） |
| **理论基础** | 有清晰的优化目标 |
| **可解释性** | 特征向量可解释为"平滑标签" |
| **效率** | 只需计算特征值（稀疏矩阵可加速） |

### 局限

| 局限 | 说明 |
|------|------|
| **尺度敏感** | 需要选择合适的相似度/邻域参数 |
| **信息损失** | 仅用前 $k$ 个特征向量 |
| **后处理依赖** | k-means 假设对球形簇有效 |
| **大规模数据** | 特征分解 $O(n^3)$ 难以扩展 |

> [!warning] 注意事项
> - 相似度矩阵的构造至关重要（$\varepsilon$-邻域、$k$-近邻、全连接）
> - 特征向量数目通常取 $k$ 或稍大
> - 对噪声和离群点敏感

## 本章知识脉络

```
图划分问题
    │
    ├─→ 目标函数 ────→ RatioCut / Ncut
    │
    ├─→ 拉普拉斯矩阵 → L = D - W（半正定、二次型）
    │
    ├─→ 谱松弛 ──────→ 离散 → 连续（瑞利商 → 特征向量）
    │
    ├─→ 二划分 ──────→ Fiedler 向量
    │
    └─→ k-划分 ──────→ 前 k 特征向量 + k-means
```

   - 谱嵌入（Spectral Embedding）
