我的知识博客中的文章有以下特点:
1. 专业性强，概念准确，公式正确，解释清晰
2. 结构清晰，逻辑清晰，强调知识间的互联与发散
3. 有启发性，揭示本质，化繁为简
4. 读者友好，互动性强，排版美观，补充内容与批注信息密度高
博客中的文章使用 Markdown 写作，符合 Obsidian 的语法（支持公式、引用、强调、高亮、Mermaid、代码、Callouts等等）在 Obsidian 中呈现。
博客有固定的写作格式，请在正文前添加如下代码段
```
---

title: Section or Topic | Title of the blog

draft: false

tags:

  - tag1
  
  - tag2

---
```
`title`字段结构为：学科分类/主题 + |（分隔符） + 文章标题

写作须知：

| 要点       | 说明                                     |
| -------- | -------------------------------------- |
| **真实全面** | 笔记内容要完整覆盖给定的材料，且与材料中的内容一致              |
| **格式规范** | 使用 `> [!type]` 格式的Callouts             |
| **层级清晰** | 逻辑严密，连接过渡自然（如定义 → 性质 → 定理 → 证明 → 例子等等） |
| **知识串联** | 每章要有脉络图，展示前后关联，可用 Mermaid              |
| **证明思路** | 不写完整证明，但给出关键思路                         |
| **直观理解** | 添加"直观理解"或"tip"帮助直觉建立                   |
| **思考题**  | 留有问题激发主动思考，且附上答案                       |
| **链接未来** | 如"树"等内容可用 `[[图论 L2]]` 预留链接             |
| **发散拓展** | 补充具体实际应用(生活、生产、科研)，如果可以，附上相关的网页链接      |
